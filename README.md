# ระบบแจ้งซ่อมออนไลน์ คณะการแพทย์แผนไทย (v16.2)

## โครงสร้างไฟล์ (อัปโหลดขึ้น GitHub ทั้งหมด โดยคงโฟลเดอร์ไว้ตามนี้)
```
index.html        หน้าหลัก + เวอร์ชันโปรแกรม (APP_VERSION)
manifest.json     ข้อมูลแอปบนมือถือ
sw.js             ตัวเก็บไฟล์ไว้ใช้ตอนเน็ตหลุด
icon-192.png, icon-512.png
richmenu.png      รูปเมนู 6 ปุ่มของ LINE OA (ระบบดึงไปตอนกด "ติดตั้งเมนู LINE")
css/app.css       หน้าตา/สี/ธีมทั้งหมด
js/core.js        ค่าตั้งต้น · API · สิทธิ์ · คิวบันทึก · ตัวช่วย (escHtml, html``) · ล็อกอิน · เราเตอร์หน้า
js/report.js      แจ้งซ่อม · ใบที่ฉันแจ้ง · งานที่ฉันรับผิดชอบ · จุดซ่อมซ้ำ · KPI
js/status.js      ติดตามงาน · ส่งออก Excel/PDF
js/workflow.js    อนุมัติ · จัดการงาน
js/dashboard.js   Dashboard · PM · ปฏิทิน · ตัวกรอง
js/admin.js       ตั้งค่า · ผู้ใช้/บทบาท · แจ้งเตือน · กติกาวิ่งงาน · คลัง · จัดการระบบ
js/detail.js      รายละเอียดใบงาน · รูปภาพ · แก้ไข/ยกเลิก · ประเมิน
js/offline.js     โหมดออฟไลน์: คิวรูปภาพ (IndexedDB) + ป้าย "รอส่ง N รายการ"
js/help.js        หน้าวิธีใช้ (สอนผูก LINE / ติดตามงาน ทีละขั้นตอน)
js/init.js        เริ่มโปรแกรม · ธีม · ตรวจเวอร์ชันใหม่
```
ไฟล์ js โหลดตามลำดับใน index.html และใช้ตัวแปรร่วมกัน (ห้ามสลับลำดับ)

## ออกเวอร์ชันใหม่
1. แก้ `APP_VERSION` ใน index.html และเลข `?v=` ท้ายชื่อไฟล์ css/js ให้ตรงกัน
2. แก้ `CACHE` ใน sw.js ให้เป็นชื่อใหม่
3. ถ้าเปลี่ยน Code.gs ให้แก้ `SERVER_REQUIRED` ใน js/core.js

## ฝั่งเซิร์ฟเวอร์ (Code.gs)
- เพิ่มคำสั่งใหม่ = เพิ่ม 1 บรรทัดในตาราง `ROUTES` (กำหนดสิทธิ์ public / user / engineer / cap:xxx และ read)
- อ่านแท็บตามชื่อคอลัมน์ด้วย `table_(ชื่อแท็บ)` แทนการนับเลขคอลัมน์
